# Abhidhammattha-saṅgaha Library

Study editions of the Abhidhammattha-saṅgaha of Ācariya Anuruddha — its Pāli text, its
commentaries and its English translations — as a static website, built like the
Dhammasaṅgaṇī Library (etomelk/dhammasangani-library): one reader per book sharing the same
template, stylesheet and script, and the Saṅgaha's own chapters and paragraphs as the
common map between the books.

**Status: in progress.** The reader and the build scripts are copied from the Dhammasaṅgaṇī
Library; the books are being added.

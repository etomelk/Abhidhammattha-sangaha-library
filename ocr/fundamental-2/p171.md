### 2. The Way of *Paṭṭhāna*

*Paṭṭhāna* means a condition which is the source of phenomena. A Canonical text in which such conditions are explained is also called *Paṭṭhāna*.

In the *Paṭṭhāna* treatise, there are 3 main points:

(1) *paccaya* = conditioning state,

(2) *paccayuppanna* = conditioned state,

(3) *paccayasatti* = conditioning force.

***Paccaya*:** There are 5 things in *paccaya* as the 4 ultimate realities and 1 concept.

***Paccayuppanna*:** In *paccayuppanna* there are only 3 ultimate realities as *citta*, *cetasika* and *rūpa*.

|---|---|---|---|
| 1 | consciousness | 1 | consciousness |
| 2 | mental state | 2 | mental state |
| 3 | matter | 3 | matter |
| 4 | *Nibbāna* | | |
| 5 | *Paññatti* | | |

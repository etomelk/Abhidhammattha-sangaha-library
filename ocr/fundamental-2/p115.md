### Mental process with Great Object

Regarding the great object, 2 types of mental process are possible to run with the great object. There are 2 or 3 *bhavaṅga*s that passed and there do not arise *tadārammaṇa*. The mental process running with a great object ends in *javana*.

### Mental process with Small Object

Regarding the small object, 6 types of mental process are possible to run with the small object. There passed from 4 to 9 *bhavaṅga*s. The mental process that runs with a small object ends in *voṭṭhapana*.

### Mental process with Very Small Object

Regarding the very small object, there arise just *bhavaṅga*. The very small object makes *bhavaṅga* vibrate, but not cease. There do not arise any active minds (*vīthi-citta*s).
